# Activity log

This is your process record. Write it in your own words. An agent may remind you of the order of events. You decide what the log says.

There is no point value in this file.

Add a row when something meaningful happens: you chose the question, you accepted or rejected a plan, you checked a source, you rejected a claim, you edited the final brief.

| When (your clock) | What I decided or asked | What an agent did, if I used one | What I checked myself |
| --- | --- | --- | --- |
| Example row, not a real session | I have not started. I will delete this row. | No agent has worked in this copy yet. | I have not checked a source yet. |

If you never had an agent, write "No agent" in the agent column and keep the other columns honest.

## Short close

When you stop, add a few lines:

- The recommendation I kept:
- What I would ask differently next time:
- Whether an agent was available:

A finished log can be short. It needs to be true for your copy of the work.
